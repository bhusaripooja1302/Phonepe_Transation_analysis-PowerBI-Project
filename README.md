
 #PhonePe Transaction Analysis – Power BI Project

📌 Project Overview

This project analyzes PhonePe transaction data using Microsoft Power BI to understand transaction trends, user behavior, service performance, and customer segments.

The dashboard provides an interactive and visual representation of key payment insights to help understand how users interact with different PhonePe services.

🎯 Project Objectives

- Analyze overall transaction volume and transaction value.
- Understand transaction trends over time.
- Analyze user contribution across different age segments.
- Identify top users based on transaction value.
- Compare weekday and weekend transaction activity.
- Analyze transaction value across different PhonePe services.
- Track important business KPIs through an interactive dashboard.

🛠️ Tools & Technologies

- Power BI – Dashboard development and data visualization
- Microsoft Excel – Dataset
- Power Query – Data transformation and cleaning
- DAX – Measures and KPI calculations

📊 Key KPIs

- Total Transactions: 300K
- Total Transaction Value: ₹3.47 Billion
- Unique Users: 96%
- Successful Transactions: 108K

📈 Dashboard Visualizations

The dashboard includes:

- Transactions Over Time – Shows transaction trends across months.
- Age Segment Contribution – Shows contribution from Gen X, Millennials, Gen Z, and Boomers.
- Service Transaction Value Analysis – Compares transaction value across PhonePe services.
- Top 5 Users – Highlights users with the highest transaction value.
- Weekday vs Weekend Usage – Compares transaction activity across days.
- Interactive Filters – Allows users to explore the dashboard based on month and payment status.
- Insights Section – Highlights important findings from the analysis.

🔍 Key Insights

- Weekdays show higher transaction activity compared with weekends.
- Loans is one of the highest-value services in the analysis.
- Different age groups contribute significantly to PhonePe transactions.
- Transaction value remains relatively consistent across the analyzed months.
- The dashboard helps identify high-value users and major transaction categories.

This project demonstrates the use of Power BI for real-world transaction data analysis. The interactive dashboard converts raw transaction data into meaningful business insights and helps identify transaction patterns, customer behavior, and service performance.
